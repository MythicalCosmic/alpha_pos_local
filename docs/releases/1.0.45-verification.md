# Alpha POS 1.0.45 — release verification

The server and delivery app are deployed. Desktop 1.0.45 is published on the
control server. The restaurant tunnel still reports 1.0.41; operator installation
is required for the local waiter fixes.

[Download AlphaPOS 1.0.45 Setup](https://control.78.111.91.113.nip.io/updates/installers/AlphaPOS-1.0.45-Setup.exe).
Install under the existing Windows account after checkout stops, preferably after
shift close, preserving the existing data directory and a current backup. Verify
Smart POS 0.0.11 or newer, cash/card checkout, waiter-to-cashier handoff, and sync
queue drain before wider rollout.

## Included fixes

Waiter attribution survives cashier settlement and synchronization. Configurable
collection and shift policies enforce explicit permissions. Table claims and
order retries are atomic. Stock timing covers actual creation and instant items;
stock failures roll back all lines. Courier assignment now uses PostgreSQL-safe
locks. Loyalty uses signed ledger changes, immutable policy/reward snapshots,
verified receipts, expiry/cancellation, and durable request replay.

No waiter frontend was added. The current waiter feature setting is disabled;
Manager/Admin can configure the local backend at `GET/PUT /api/waiters/settings`.
Cloud settings do not distribute this local policy. Existing explicit staff
permission lists are preserved.
